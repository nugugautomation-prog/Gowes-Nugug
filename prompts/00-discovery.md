# 00 — Discovery

Saya akan membuat software project baru.
Untuk tahap ini jangan coding. Bantu saya melakukan discovery.

Tanyakan tentang:
1. Masalah bisnis
2. Tujuan project
3. Target user
4. Proses bisnis saat ini
5. Masalah proses saat ini
6. Proses yang diinginkan
7. Data
8. Output
9. Role
10. Aturan bisnis
11. Integrasi
12. Batasan
13. Out of scope
14. Risiko dan edge case

Jangan membuat PRD, architecture, atau coding. Jangan mengarang proses bisnis. Jika jawaban belum jelas, gali lebih lanjut. Tujuan akhirnya adalah bahan untuk `docs/PROJECT-CONTEXT.md`.
