# 03 — Create PRD

Gunakan `docs/PROJECT-CONTEXT.md` dan `docs/BRAINSTORMING-SUMMARY.md`.
Buat `docs/PRD.md` mencakup:
1. Product Overview 2. Problem Statement 3. Goals 4. Non Goals 5. Target Users 6. User Roles 7. Features 8. Functional Requirements 9. Non Functional Requirements 10. Business Rules 11. Permission Requirements 12. Workflow 13. Validation 14. Error Handling 15. Edge Cases 16. Acceptance Criteria 17. Reporting 18. Audit Trail 19. Data Requirements 20. Out of Scope 21. Dependencies 22. Risks

Gunakan requirement ID seperti FR-001, BR-001, PER-001, AC-001. Setiap feature punya acceptance criteria. Jangan coding. Jika requirement ambigu, STOP.
